# Launch_Lab_Program_AI_Case
Build an AI agent that, given a user-supplied regulatory law, automatically retrieves authoritative sources, extracts the sensitive data entities and enforcement-relevant obligations, maps them to NetApp's existing detector taxonomy, and auto-generates assets (regex, dictionaries, validation rules) for any gaps—delivering “day-0” support.

Business Context
-----------------------
Regulatory changes are outpacing vendor-driven support for sensitive data detection. When
new laws or amendments land (e.g., “CPRA 2023” or the “HIPAA Privacy Rule”), enterprises
face a coverage gap between the obligations a regulation imposes and the detectors that data
platforms ship. NetApp's Console Classification and PII Detection capabilities depend on well-
defined sensitive-entity detectors, and closing new gaps quickly is a competitive and compliance differentiator.

Target Users
• Compliance and data governance teams responsible for mapping regulations to
enforceable controls.
• NetApp product and engineering teams maintaining BlueXP Classification / PII detection
coverage.
• Enterprise customers who must demonstrate audit-ready coverage of new and amended
regulations.
Objectives
• Extract sensitive data entities and enforcement-relevant obligations directly from
regulatory text with high precision and recall.
• Map extracted entities to NetApp's existing detector taxonomy and surface coverage gaps.
• Auto-generate candidate detector assets (regex, dictionaries, validation tests) for
uncovered entities.
• Drastically reduce time-to-support and enable incremental updates when laws are
amended.
